1. CRITICAL ISSUES (P1 - MUST FIX)
================================================================================

[ ] Remove Global State
    Location: scanner.c:7
    Problem: Scanner is a global static variable
    Impact: Thread-unsafe, can't have multiple concurrent parsers
    Fix: Pass Scanner* as parameter to all functions
    Example:
        Before: void initScanner(char *source)
        After:  Scanner* scanner_init(const char *source, MemPool *pool)

[ ] Add Input Validation Layer
    Location: grammar.c:235-268 (fillGrammarNode)
    Problem: No bounds checking, can stack overflow with malformed grammar
    Impact: Crashes with invalid input
    Fix: Add validation before parsing
        - Validate token stream bounds
        - Add maximum recursion depth limit
        - Check for circular grammar dependencies
        - Validate grammar rules before building tree

[ ] Type-Safe Error Handling
    Location: All try* functions (parser.c, grammar.c)
    Problem: Returns magic integers (0, 1, 2, 3...) with no context
    Impact: Hard to debug, can't provide meaningful error messages
    Fix: Create error enum and struct
        typedef enum {
            PARSER_OK = 0,
            PARSER_NOT_INITIALIZED,
            PARSER_GRAMMAR_LOAD_FAILED,
            PARSER_INVALID_GRAMMAR,
            PARSER_NO_TOKENS,
        } ParserErrorCode;

        typedef struct {
            ParserErrorCode code;
            char message[256];
            size_t line;
            size_t column;
        } ParserError;

[ ] Separate Mixed Concerns
    Problem: Debug printing, file I/O, and core logic all mixed together
    Impact: Hard to maintain, test, and reuse
    Fix: Create separate modules:
        - debug/ for all printing functions
        - io/ for file operations
        - core/ for parsing logic only

5. SPECIFIC CODE AREAS REQUIRING REFACTORING
================================================================================

[ ] grammar.c:212-468 - fillGrammarNode() (BIGGEST MESS)
    Problems:
        - Single function tries to handle all node types
        - Token offset arithmetic everywhere (start + delimOffset + 1)
        - Highly recursive with no depth limit
        - Comment admits: "doesn't do any checks!!"

    Refactor approach:
        1. Create TokenStream abstraction:
           typedef struct {
               Token *tokens;
               size_t len;
               size_t pos;
           } TokenStream;

        2. Split into focused functions:
           static int parse_and_node(TokenStream *ts, RuleNode *out);
           static int parse_or_node(TokenStream *ts, RuleNode *out);
           static int parse_group_node(TokenStream *ts, RuleNode *out);

        3. Add validation wrapper:
           int fillGrammarNode_safe(RuleNode *node, Token *tokens,
                                     size_t n, MemPool *pool);

[ ] ast.c:75-111 - parseAnd() (Complex Branching)
    Problems:
        - 3 levels of nested conditions
        - Multiple special cases for optional nodes
        - STX_ERROR nodes treated specially
        - Hard to follow logic

    Fix: Extract conditions into named helpers
        static bool is_optional_rule(RuleNode *rule);
        static bool should_inline_children(SyntaxNode *node);

[ ] scanner.c:7 - Global Scanner State
    Problem: static Scanner scanner;
    Fix: Remove global, pass as parameter

[ ] All files - Debug Output Mixed with Logic
    Problem: printSyntaxNode(), printGrammarNode(), etc. everywhere
    Fix: Create debug/ module with unified interface:
        void debug_print_ast(DebugLevel level, SyntaxNode *node, FILE *out);
        void debug_print_grammar(DebugLevel level, GrammarRule *rule, FILE *out);

[ ] Scattered Utility Functions
    Problem: __printNTabs(), __swapSyntaxNodes() duplicated
    Fix: Create utils/ module with common helpers

[ ] parser.c - Grammar Validation Commented Out
    Problem: Grammar validation code exists but is disabled
    Fix: Re-enable and improve validation logic

7. API DESIGN IMPROVEMENTS
================================================================================

Current API Issues:
    - Unclear naming (trySetParserGrammar)
    - Exposed internal state
    - No clear error context
    - Parsing step is missing/unclear

Recommended API Design:

    /* Initialization */
    Parser* parser_create(const ParserConfig *config);
    void parser_destroy(Parser *p);

    /* Configuration */
    ParserError parser_set_grammar(Parser *p, const char *grammar_file);
    ParserError parser_set_grammar_string(Parser *p, const char *grammar_str);

    /* Parsing */
    ParserError parser_tokenize(Parser *p, const char *source);
    ParserError parser_parse(Parser *p, SyntaxNode **out_ast);

    /* Convenience */
    ParserError parser_parse_file(Parser *p, const char *source_file,
                                   SyntaxNode **out_ast);

    /* Introspection */
    const char* parser_error_message(const ParserError *err);
    size_t parser_error_location(const ParserError *err, size_t *line, size_t *col);

    /* Debug */
    void parser_set_debug_level(Parser *p, DebugLevel level);
    void parser_dump_ast(Parser *p, FILE *out);
    void parser_dump_grammar(Parser *p, FILE *out);

Usage Example:

    ParserConfig config = {
        .max_rule_depth = 100,
        .debug = DEBUG_NONE,
        .external_pool = NULL
    };

    Parser *p = parser_create(&config);

    ParserError err = parser_set_grammar(p, "grammar.txt");
    if (err.code != PARSER_OK) {
        fprintf(stderr, "Grammar error: %s\n", err.message);
        parser_destroy(p);
        return 1;
    }

    SyntaxNode *ast;
    err = parser_parse_file(p, "source.tl", &ast);
    if (err.code != PARSER_OK) {
        size_t line, col;
        parser_error_location(&err, &line, &col);
        fprintf(stderr, "%zu:%zu: %s\n", line, col, err.message);
        parser_destroy(p);
        return 1;
    }

    // Use AST...

    parser_destroy(p);
